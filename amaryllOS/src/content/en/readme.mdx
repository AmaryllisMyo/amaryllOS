## Hi!
### Thank you for the time spent browsing my personal website :D 

If you want to find out more about my design process, you can find the project at this [Figma link](https://www.figma.com/design/CUcdHuRECVNLBYd2KAwNws/AmaryllisSito?node-id=0-1&t=Cm6Z0zjJ5soREGiH-1).  
This website was built using **Vite**, **React** and **TypeScript**.
Styling is done with **CSS Modules** and a set of design tokens, and the site is available in English and Italian thanks to **i18next**.

As for the doodleboard, it's rendered as a SVG and its state is managed through Immutable.js. Drawings are exported to JPEG and sent to my inbox using EmailJS!
